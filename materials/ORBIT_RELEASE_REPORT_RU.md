# ORBIT v0.3 — отчёт о выполненной работе

Дата: 16 ноября 2026 года. Этот отчёт относится к локально созданному и проверенному релизу, **не к завершённой публикации в GitHub**.

## Создано

Новый обученный предиктор действий, планировщик из 27 кандидатов, игра ORBIT на русском/английском/упрощённом китайском, дневной режим, свободная лаборатория, визуализация прогнозов и признаков, карточки PNG, отдельные таблицы алгоритмов/локальных попыток/публичных повторов. Подготовлены проверка JSON-повторов, GitHub Actions workflow и `publish.command` с браузерной авторизацией.

## Обучение

Визуальный энкодер и координатный считыватель взяты из предыдущего проекта без изменения весов. Обучен новый предиктор на 23 192 параметра. Данные: 65 536 независимых синтетических траекторий, seed 31001, 5 000 шагов AdamW, batch 256, CPU. Отдельная валидация: 2 048 траекторий, seed 31002. Выбран checkpoint шага 5000 по минимальной валидационной ошибке признаков. История: `artifacts/action_jepa/history.json`; настройки и версии: `training.json`; журнал: `docs/v03/training.log`.

Два изображения 24 × 24 → два вектора по 8 признаков → предиктор вместе с 3 действиями → три будущих вектора. Ошибка обучения вычисляется только по признакам; координатные метки, скорости, физическая формула и награда не передаются в целевую функцию. Старый визуальный энкодер не переобучался. Это перенос уже обученного представления, а не обучение всей системы с нуля.

Планировщик выбирает действие по нормированному расстоянию до признаков изображения цели. Координатный probe обучен с метками, но в выборе плана не используется. План открытый, из трёх действий; замкнутое MPC с новыми наблюдениями после каждого действия не реализовано.

## Измерения

1 024 новых сцены, namespace `held-out-orbit-20261116`, все 27 последовательностей действий на каждой сцене. Модель при выборе плана не получает точные позиции. Радиус попадания: 0,06 нормализованных единиц = 1,38 пикселя в шкале `(24 - 1)`. Случайный выбор и перестановки используют отдельный RNG seed 99017.

| Вариант | Попадание в цель | Среднее расстояние до цели |
|---|---:|---:|
| Физический эталон с точным состоянием | 100,0% | 0,186 пикселя |
| JEPA-планировщик | 67,8% | 0,942 пикселя |
| Без толчков | 23,7% | 3,411 пикселя |
| Случайная перестановка соответствия план–действие | 21,7% | 4,290 пикселя |
| Случайный план | 19,5% | 4,322 пикселя |

Средняя ошибка *предсказанного положения* для всех кандидатов — 1,463 пикселя. Это не то же самое, что фактическое расстояние до цели после исполнения выбранного плана. Для hit-rate в JSON приведены интервалы Wilson; для средних — нормальная аппроксимация доверительного интервала. Один обучающий seed не отражает разброс между переобучениями.

Эталон знает точные координаты и физику — у него привилегированная информация. Реальные LLM, роботы и внешние JEPA-модели не участвовали в сравнении. Прогнозов качества на реальном мире и доказательства превосходства над LLM здесь нет.

## Выполненные тесты

**31 Python-тест:** включая прежнюю лабораторию, заморозку энкодера, градиенты нового предиктора, формы входов, влияние действий, воспроизводимость симулятора, соответствие физики Python/JavaScript, соответствие нейросетевого предсказания Python/JavaScript, ключи переводов и статическую сборку.

**38 Node-тестов:** прежние правила игры, 27 вариантов планов, отражения, достижимость целей, действие шума только на наблюдение, границы очков, отсутствие мутаций входа, строгая валидация повторов, отказ от присланных очков, даты/версии/размеры, недопустимые значения, идентификация через GitHub metadata, обработка вредоносных строк как данных, ограничение 500 issues.

**137 браузерных утверждений:** Chromium через Playwright, RU/EN/简体中文, ширины 1440/390/320 CSS-пикселей, клавиатура, скрытие ответа до хода, фиксация плана, пять раундов, сохранение карточек, переключение языка без сброса, локальная таблица и удаление записей, честное предупреждение при запрете persistent storage, пустой публичный рейтинг без вымышленных людей, лабораторные прогнозы, выбор JEPA, влияние шума и исключение лаборатории из дневного рейтинга. Это число утверждений, а не 137 независимых научных экспериментов.

Выполнен новый `ORBIT_Action_Planning.ipynb`: 5 ячеек кода, без ошибок, на CPU с опубликованными весами. В нём показан выбор плана в пространстве признаков и отдельная проверка в симуляторе.

Журналы: `docs/v03/python_tests.log`, `node_tests.log`, `browser_tests.json`. В проверенных сценариях не было непойманных JavaScript-ошибок и запросов к сторонним сервисам.

## Ограничения проверки

Политика Chromium в рабочей среде блокирует навигацию `file://` с `ERR_BLOCKED_BY_ADMINISTRATOR`. Политика не изменялась и не обходилась. Браузерные проверки выполнены через `set_content` с локальным автономным HTML. Это проверяет реальный JavaScript, DOM, нейросетевые вычисления, PNG и вёрстку, но не сетевую доставку сайта.

**Не проверены:** реальный GitHub Pages, HTTPS/CORS, GitHub OAuth и CLI против аккаунта владельца, workflow в облаке, живая отправка issue, сетевое обновление рейтинга, долговременное хранилище с настоящим origin, настоящие телефоны, Safari, Firefox и доступность из материкового Китая. Проверка китайского носителем языка не заявляется.

`publish.command` проверен через `bash -n`; это не равно проверке его внешних API-вызовов. Токен пользователя не был доступен. Репозиторий не создан, ветка не отправлена, живой адрес не подтверждён.

## Границы рейтинга

Локальные очки — недоверенные данные. Публичная запись содержит публичный логин GitHub и валидированный повтор; баллы пересчитываются. Это не доказывает игру человека без подсказок. Боты и перебор разрешённых планов возможны. Таблица асинхронная, ограничена последними 31 датами UTC и 500 недавно обновлёнными issues. Публикация записи требует явного действия игрока на GitHub.
