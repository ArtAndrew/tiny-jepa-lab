## ORBIT — a world model you can play

**An educational world-model demo in the form of a browser game.** A tiny JEPA-inspired neural network predicts the effects of actions, compares 27 plans, and chooses how to guide a ball toward a target. Pick your own plan and see what actually happens.

[Play](https://artandrew.github.io/tiny-jepa-lab/) · [Русский](https://artandrew.github.io/tiny-jepa-lab/ru/) · [中文](https://artandrew.github.io/tiny-jepa-lab/zh/)

- Five daily rounds plus a free playground.
- Trained neural inference runs locally in the browser; no sign-up to play.
- Clear action labels, a visual explanation of world models and JEPA, and a comparison with text generation by LLMs.
- English, Russian, and Simplified Chinese; light, dark, and automatic themes.
- Shareable result cards and an optional GitHub leaderboard with recomputed scores.
- Illustrated replay, social preview images, and multilingual README files.

The world is intentionally small: a ball, walls, and a target. The model predicts numerical features, not future video frames. This is an independent educational implementation, not Meta's V-JEPA model. The original training report is preserved; this release does not claim a new training run or independently reproduced benchmark.

## По-русски

**ORBIT — учебное демо модели мира, в которое можно сыграть.** Нейросеть прогнозирует последствия действий и использует этот прогноз для выбора плана. Весь её «мир» — шарик, стены и цель.

Выбери три действия, сравни свой план с AI и посмотри, где прогноз помог, а где модель ошиблась. Для игры не нужна регистрация. Для отправки в общий рейтинг потребуется аккаунт GitHub.

В этой публикации: понятное объяснение модели мира, анимация реального раунда, README на трёх языках, обложки для ссылок, светлая/тёмная/автоматическая темы и проверяемый общий рейтинг.
